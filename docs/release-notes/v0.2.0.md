Inky 0.2 apporte la mise en forme automatique, le dictionnaire personnel et les mises à jour automatiques.

## Nouveautés
- **Mise en forme**, tout désactivable dans Réglages › Mise en forme :
  - auto-corrections orales : « rendez-vous à 14 h, non plutôt 15 h » → « rendez-vous à 15 h » ;
  - commandes vocales : « à la ligne », « nouveau paragraphe », « point d'interrogation », « ouvrez les guillemets »… ;
  - listes numérotées : « premièrement… deuxièmement… » ;
  - style messagerie : pas de point final dans Messages, Slack, Discord, WhatsApp… ;
  - espacement intelligent quand tu dictes juste après un mot.
- **Dictionnaire** : mots et noms propres, corrections automatiques, snippets (« mon adresse mail » → ton adresse).
- **Pastille** :
  - « Attends… » (jaune) tant que le micro démarre, puis rouge avec un chronomètre : parle quand elle est rouge ;
  - petite pastille toujours visible, même en plein écran ; clique dessus pour dicter en mains libres ;
  - chaque élément se désactive, et « Inky activé » dans le menu met tout en pause.
- **Mises à jour automatiques** depuis GitHub (vérifiées par SHA-256 et par la signature). Réglages › À propos.
- **Tutoriel** interactif (menu › Tutoriel…).
- Diagnostic du délai de démarrage du micro (Réglages › Audio).

## Installation
La v0.1 ne savait pas se mettre à jour : télécharge `Inky-0.2.0.zip`, puis remplace l'app dans `/Applications`. Les versions suivantes s'installeront toutes seules.

L'app n'est pas notarisée : au premier lancement, va dans *Réglages Système › Confidentialité et sécurité*, puis clique sur « Ouvrir quand même ».
